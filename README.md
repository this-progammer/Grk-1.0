# GRK-1.0
Graphics Runtime Kit Project 1.0 2027 Source Package


# -----*PACKAGES*-----
  -GRK ( Graphics Runtime Kit )
  -GPICL ( Graphics Picture Library )
  -GTEXL ( Graphics Text Library )
  

# GRK
  Renders Widgets And Colors To The Desktop Screen
  

# GPICL
  Renders Pictures And Images
  

# GTEXL
  Renders Text And Fonts

# Intended Use 
  Intended For GUI Of A Unreleased Operating System, That Yet Will Not Be Named Or Released.

# Architecure
  X64_DEBUG.
  X64_RELEASE.

# Programmers Manual
  Script Files Are To Be Written In Python.
  Source Files Are To Be Written In C++.
  Graphics Hardware Management Should Be Written In x86ASM.

# Build
  $(pkg-config -./grk/ -./gpicl/ -./gtextl/) <arch_type> -o $.grkpkg
